TPP
===

A Python/Django web application for querying, displaying and filtering information about mathematical objects called TPP triples, which are associated with finite groups.  This information is currently a "raw" dataset, to be precise, several HTML tables containing around several million records (but not more than 12 million) - <a href="http://www2.informatik.uni-halle.de/da/hedtke/tpp/" target="_blank">get it here</a>.  The dataset was extracted from the <a href="http://gap-system.org/Packages/sgl.html" target="_blank">Small Groups data library</a> of the <a href="http://gap-system.org" target="_blank">GAP computer algebra system</a> by fast search programs written in the GAP programming language - <a href="http://www2.informatik.uni-halle.de/da/hedtke/tpp/algorithms.txt" target="">get the source code</a>.  The algorithms on which the search programs were based is described in the journal paper I. Hedtke, S. Murthy, ’Search and test algorithms for triple product property triples’, Groups - Complexity - Cryptology, 4(1): 111-133, 2012.  This and other papers about TPP triples are listed below.

1. I. Hedtke,  S. Murthy et.al., A fast search algorithm for TPP
triples and an application for 5 x 5 matrix multiplication’, Groups - Complexity - Cryptology, to appear in May 2015.

2. S. Murthy & M. Lång, 'The Triple Product Ratio and Groups with Abelian Normal Subgroups of Prime Index', private research note, Jul. 2014.

3. I. Hedtke, S. Murthy, ’Search and test algorithms for triple product property triples’, Groups - Complexity - Cryptology, 4(1): 111-133, 2012.
 
4. Peter M. Neumann, ’A note on the triple product property for subsets of finite groups’, LMS J. Computation and Mathematics, 14:232-237, 2011.
 
5. H. Cohn, R. Kleinberg, B. Szegedy, C. Umans, ’Group-theoretic algorithms for matrix multiplication’, in: Proceedings of the 46th Annual Symposium on Foundations of Computer Science (Pittsburgh 2005), IEEE Computer Society (2005), 379-388.

6. H. Cohn, C. Umans, ’A group-theoretic approach to fast matrix multiplication’, in: Proceedings of the 44th Annual Symposium on Foundations of Computer Science (Cambridge, Massachusetts 2003), IEEE Computer Society (2003), 438-449.
