TPP
===

A web application for querying, displaying and filtering information about mathematical objects called TPP triples, which are associated with finite groups.  This information is currently in the form of HTML tables containing several million records) - <a href="http://www2.informatik.uni-halle.de/da/hedtke/tpp/" target="_blank">see here</a>.  TPP triples and their applications are described in the following papers (in chronological order).

H. Cohn, C. Umans, ’A group-theoretic approach to fast matrix multiplication’, in: Proceedings of the 44th Annual Symposium on Foundations of Computer Science (Cambridge, Massachusetts 2003), IEEE Computer Society (2003), 438-449.

H. Cohn, R. Kleinberg, B. Szegedy, C. Umans, ’Group-theoretic algorithms for matrix multiplication’, in: Proceedings of the 46th Annual Symposium on Foundations of Computer Science (Pittsburgh 2005), IEEE Computer Society (2005), 379-388.

Peter M. Neumann, ’A note on the triple product property for subsets of finite groups’, LMS J. Computation and Mathematics, 14:232-237, 2011.

I. Hedtke, S. Murthy, ’Search and test algorithms for triple product property triples’, Groups - Complexity - Cryptology, 4(1): 111-133, 2012.

S. Murthy & M. Lång, 'The Triple Product Ratio and Groups with Abelian Normal Subgroups of Prime Index', private research note, Jul. 2014.

I. Hedtke,  S. Murthy et.al., A fast search algorithm for TPP
triples and an application for 5 x 5 matrix multiplication’, Groups - Complexity - Cryptology, to appear in May 2015.

The application will be developed using the Python/Django framework.
