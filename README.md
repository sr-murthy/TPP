Repository of Code and Data for the TPP Search Project
======================================================

The [GAP system](https://www.gap-system.org/) code and data in this repository is related to a computational project carried out as part of research for the jointly-authored and published paper with I. Hedkte:

I. Hedtke and S. Murthy, 'Search and test algorithms for triple product property triples', \emph{Groups - Complexity - Cryptology}, 4(1): 111-133, 2012. DOI: [https://doi.org/10.1515/gcc-2012-0006](https://doi.org/10.1515/gcc-2012-0006)

The GAP system version used for this particular project was 4.4.12 (2008).

The code was executed on supercomputers at the Friedrich Schiller University, Jena and the Martin Luther University, Halle-Wittenberg in Germany during 2011-2012, but this author also tested and run parts of the code locally on a 2011 MacBook Air.
